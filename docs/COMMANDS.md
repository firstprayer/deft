# Command reference

Generated by `cargo xtask site` from the command registry. Do not edit this file; change the operation in `crates/deft-ops/src/ops/`. For options, run `deft <group> <command> --help`.

A command marked ffmpeg needs that program installed. See [INSTALL.md](INSTALL.md).
